# Annur.Vita — прототип

HTML-прототип для клиента: онлайн-магазин натуральной продукции с единым каталогом,
двумя витринами (веб + Telegram Mini App) и ИИ-сотрудником, который консультирует
и оформляет заказы в чатах.

- `index.html` + `style.css`, без сборки — открывается локально или с GitHub Pages.
- Товары взяты из канала клиента https://t.me/Annurvitaanaturalproduct;
  цены, сроки и остатки в макетах условные.
- Разделы: схема трафика (веб + Telegram), веб-витрина, Telegram Mini App,
  ИИ-сотрудник, админка товара, статусы заказа, доставка (Яндекс по России,
  Азия и Ближний Восток).
